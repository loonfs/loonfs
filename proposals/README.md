# Proposals

This directory is the only place where the rewrite may suggest changes to the locked spec set.

Rules:

- never edit `docs/specs/*` directly on this branch
- put one meaningful change set in one proposal file
- name the affected spec files explicitly
- say whether the proposal is clarifying, narrowing, superseding, or intentionally diverging
- implementation may follow a divergence only when the proposal says that explicitly

Start from [`TEMPLATE.md`](TEMPLATE.md) for new proposal documents.
